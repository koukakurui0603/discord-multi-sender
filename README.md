# Discord マルチ転送ボタン (Discord Multi Sender)

今ブラウザで開いているWebページ（記事、動画、SNSポストなど）の「タイトル」と「URL」を、**ワンタップで指定したDiscordチャンネルへ仕分け送信できる**ブラウザ拡張用スクリプトです。

* 右下に小さな折り畳みボタン（`📂`）が待機し、タップした時だけ上に10個（追加も可）の振り分けボタンが展開します。片手（親指）だけで操作が完結する配置になっています。
* 振り分け先のWebhook URLはスクリプト本体に書かず、**内蔵のビジュアル設定画面（配置プレビュー＆JSONファイル出力・読込機能つき）** から安全に設定・管理できます。

## 1. 事前準備（Tampermonkeyを入れる）

お使いのブラウザに拡張機能 **「Tampermonkey（タンパーモンキー）」** を追加します（無料）。

### Androidスマホ・タブレット（Firefox）の場合
1. Android版 **Firefox** を開き、右上のメニュー（`⋮`）→ **「拡張機能」** を開きます。
2. 一覧から **「Tampermonkey」** を探して「＋」ボタンで追加します。

### パソコン（Chrome / Edge / Firefox）の場合
1. 各ブラウザの拡張機能ストアから **「Tampermonkey」** をインストールします。
2. **※Chrome / Edge をお使いの場合の重要設定：**  
   ブラウザ右上のメニュー →「拡張機能」→「拡張機能を管理」を開き、画面右上にある **「デベロッパーモード」をON**（またはTampermonkey詳細画面の「ユーザースクリプトを許可」をON）にしておかないとスクリプトが動きません。

## 2. 本スクリプトをインストールする

### 方法A：PCなど（ワンクリック導入）
以下のリンクをクリックすると、Tampermonkeyのインストール画面が開きますので「インストール」を押してください。

* **[▶ discord_multi_sender.user.js をインストール](https://github.com/koukakurui0603/discord-multi-sender/raw/main/discord_multi_sender.user.js)**

### 方法B：Android版 Firefox 等でインストール画面が出ない場合（確実な方法）
スマホやタブレット版のFirefoxでは、上のリンクをタップしても文字が表示されるだけでインストール画面が開かないことがあります。その場合は以下の手順で導入してください。

1. 上のインストールリンクを **長押し →「リンクをコピー」** します。  
   （コピーするURL： `https://github.com/koukakurui0603/discord-multi-sender/raw/main/discord_multi_sender.user.js` ）
2. Firefoxのメニュー（`⋮`）→「拡張機能」→ **「Tampermonkey」** → **「ダッシュボード」** を開きます。
3. 上部（またはメニュー）にある **「ユーティリティ（Utilities）」** タブを開きます。
4. 画面下の **「URLからインストール」** の入力欄にコピーしたURLを貼り付け、**「インストール」** ボタンを押します。
5. 確認画面が出たら「インストール」を押して完了です。

## 3. 初期設定（Webhook URLとアイコンの登録）

1. インストール後、適当なWebページを開くと画面右下に **`⚙️`** ボタンが表示されますのでタップしてください。
2. ビジュアル設定画面が開きます（上部に1〜10番の配置プレビュー、下に入力枠が並びます）。
3. 好きなボタン位置に **絵文字アイコン** と、Discordで作った **Webhook URL** を入力します。
   * ※あらかじめ準備した設定JSONファイル（`buttons_sample.json` を書き換えたもの）がある場合は、右上の **「📂 JSONから読込」** から一発で読み込めます。
4. 下の **「🔍 ① Webhookから名前・接続を確認する」** を押すと、URLが正しいかチェックし、Discord側でWebhookに付けた名前を自動で右枠に表示します。
5. 確認できたら、**「💾 ② 保存してボタンに反映」** を押して完了です（必要に応じて「📥 ② 設定用JSONファイル出力」でバックアップも保存できます）。

---

## 4. 使い方

* 普段は右下に小さな **`📂`** ボタンだけが表示され、閲覧の邪魔になりません。
* 保存したいページを見たら右下の **`📂`** をタップ → 上に展開したボタンから送りたいジャンルのアイコンをタップします（`⏳` → `✅` で送信完了）。
* もう一度 **`➖`** をタップすると折り畳まれます。ボタンの配置やURLを変更したい時は、開いた時に左横に出る **`⚙️`** ボタンからいつでも設定画面を開けます。
